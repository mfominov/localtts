# Spec: Currency scale + `$1,04 млрд` (NUM)

## Status

Implemented 2026-08-20 (срез 2).

## Goal

`$1,04 млрд` и похожие суммы не ломаются в «доллар + центы + сырой млрд», а звучат правдоподобно ушам.

## Decisions (grilling 2026-08-20)

- Сокращения: `млрд` / `млн` / `тыс` рядом с числом / `$€₽`
- Запятая в `$1,04` — десятичная (не US-тысячи / не «центы» при наличии scale)
- Формулировка для scale+currency: **lossy** — «примерно один миллиард долларов США» (не тащить сотые, если есть `млрд`/`млн`/`тыс`)
- Срез 2 после numbered-list-speech; OpenSpec не трогаем

## Out of scope

- Англ. `bn` / `mln` / `k` (не в этом срезе)
- Полный accounting-grade money TTS

## Acceptance

- Unit: `$1,04 млрд` → содержит `примерно`, `миллиард`, `доллар` (или эквивалент num2words); нет сырого `млрд` и нет «цент»
- Регресс: `$100` без scale по-прежнему нормальные доллары
